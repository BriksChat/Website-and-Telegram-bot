<a id="stage-1"></a>

### 01 — Запустить локальное ядро

Ядро полностью автономно. В нём находятся 300 слов: 30 карточек по 10 слов. Каждая карточка проходит в два раунда по 5 пар «русский — английский».

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Распакуйте архив.
3. Дважды щёлкните по `start-core.bat`.

> [!TIP]
> Можно также открыть `core/index.html` обычным двойным щелчком.

<a id="stage-2"></a>

### 02 — Подключить локальный API и базу

### Быстрая подготовка в Windows

1. Запустите `scripts/setup-backend-windows.bat`.
2. Сценарий проверит Python 3.12 и начнёт установку. Вся процедура занимает примерно 2–3 минуты.
3. В корне появится локальный файл `.env`. Git его не публикует.
4. Откройте `.env` и замените значение `ADMIN_PASSWORD` на свой пароль.

> [!NOTE]
> Если автоматическая установка Python недоступна, установите Python 3.12 с сайта python.org, а затем снова запустите сценарий.

### Запуск API

**Запустить:**

```bat
scripts/start-api-windows.bat
```

Не закрывайте открывшееся окно.

**Проверить:**

```text
http://127.0.0.1:5000/api/health
```

**Правильный ответ:**

```json
{"status":"ok"}
```

> [!TIP]
> Если ничего не происходит, откройте окно `scripts/start-api-windows.bat`, нажмите Enter и перезапустите сценарий.

При первом запуске API создаст локальную SQLite-базу и заполнит её 300 словами.

### Запуск сайта, подключённого к API

Не закрывая API, запустите второе окно:

```bat
scripts/start-website-windows.bat
```

Откроется `http://127.0.0.1:8000`. Это полная версия из `website`, которая получает данные через API.

**Админ-панель:**

```text
http://127.0.0.1:8000/admin.html
```

Для входа используется `ADMIN_PASSWORD` из файла `.env`. Через панель можно добавлять, исправлять и удалять слова общего словаря.

<a id="stage-3"></a>

### 03 — Создать MySQL в Amvera

SQLite удобна для локального знакомства. Для опубликованного проекта рекомендуется MySQL.

Подробная инструкция по Amvera: [`docs/infoAmvara.md`](docs/infoAmvara.md).

1. Зарегистрируйтесь в Amvera и создайте базу MySQL.
2. Скопируйте параметры подключения и укажите их в переменной `DATABASE_URL` приложения.
3. После запуска API создаст нужные таблицы и заполнит их данными.

> [!NOTE]
> При регистрации Amvera начисляет 100 ₽ — этого достаточно, чтобы попробовать сервис и протестировать проект.

<a id="stage-4"></a>

### 04 — Опубликовать сайт и домен

1. Купите домен и хостинг на REG.RU, затем привяжите домен к хостингу.
2. Загрузите на хостинг содержимое папки `website`.

<a id="stage-5"></a>

### 05 — Создать и подключить Telegram-бота

1. Откройте `@BotFather` в Telegram, выполните `/newbot` и создайте бота **Lear English** с username **LearEnglishBot**. Если username занят, выберите свободный вариант.
2. Сохраните выданный BotFather токен.
3. В переменных окружения приложения в Amvera укажите:

| Переменная | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен BotFather. Добавьте его как секрет. |
| `TELEGRAM_BOT_USERNAME` | `LearEnglishBot` без `@`. |
| `SITE_URL` | Публичный адрес сайта. |
| `API_URL` | Публичный адрес API. |

4. Перезапустите приложение.
