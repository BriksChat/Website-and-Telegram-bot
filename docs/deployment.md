# Полная публикация LearEnglish

Основной маршрут находится в [README](../README.md). Эта страница фиксирует итоговую архитектуру и порядок публикации.

## Порядок

1. Проверить автономное ядро на ПК.
2. Создать собственный Fork.
3. Проверить API, SQLite и админ-панель локально.
4. Развернуть API и MySQL по инструкции [Amvera: API и MySQL](infoAmvara.md).
5. Развернуть сайт и админ-панель по инструкции [REG.RU](reg-ru.md).
6. Только после проверки сайта подключить [Telegram-бота](telegram-bot.md).

## Итоговая архитектура

~~~text
Сайт REG.RU ─────┐
                 ├─ API Amvera ─ MySQL Amvera
Telegram-бот ────┘
~~~

Сайт и бот никогда не подключаются к MySQL напрямую.

## Переменные API

Секреты:

- DATABASE_URL;
- ADMIN_PASSWORD;
- TELEGRAM_BOT_TOKEN — только на последнем этапе.

Обычные переменные:

- PORT=5000;
- API_URL=http://127.0.0.1:5000;
- SITE_URL=https://ваш-домен;
- CORS_ORIGINS=https://ваш-домен;
- TELEGRAM_BOT_USERNAME — только после создания бота.

## Публичная конфигурация сайта

Файл **website/config.js** содержит только публичные адреса:

~~~javascript
window.ENGLISH_API_URL = 'https://ВАШ-API.amvera.io';
window.TELEGRAM_BOT_URL = '';
~~~

После создания бота во вторую строку добавляется публичная ссылка t.me. Токен в этот файл не записывается.

## Обязательная финальная проверка

- API health возвращает status ok;
- API отдаёт 300 слов;
- сайт работает по HTTPS;
- обучение и статистика сохраняются;
- личный словарь работает;
- /admin.html позволяет редактировать общий словарь;
- изменения сохраняются после перезапуска API;
- при отсутствии токена сайт и API работают без Telegram;
- после подключения бот использует общий прогресс сайта.
