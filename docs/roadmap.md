# Маршрут развития проекта

## 1. Локальное ядро — готово

Откройте `core/index.html`. Сайт работает без интернета и без установки программ. Прогресс сохраняется только в браузере этого компьютера.

## 2. Сервер и база данных

На этом этапе появится API — программа-посредник между сайтом и базой данных. Сайт будет отправлять API результаты обучения, а API будет сохранять их в базе.

Сначала сервер можно запустить локально. Для начинающего пользователя будет подготовлена обычная инструкция и отдельный Windows-сценарий, который проверит Python, создаст окружение и установит зависимости.

После появления API можно добавить админ-панель. В ней администратор сможет управлять общим словарём без редактирования исходных файлов.

## 3. Хостинг и домен

Когда локальная версия сервера работает, сайт и API можно опубликовать в интернете. Сайт получит адрес на хостинге, а затем — собственный домен. База данных будет размещена рядом с API или в отдельном управляемом сервисе.

## 4. Telegram-бот

Последним подключается Telegram-бот. Он обращается к тому же API, что и сайт. Поэтому бот и сайт не синхронизируют две разные базы: они используют одну общую базу через API.

```text
Сайт ─┐
      ├─ API ─ общая база данных
Бот ──┘
```
