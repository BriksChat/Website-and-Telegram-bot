# Маршрут проекта

Все основные части LearEnglish уже находятся в репозитории. Этот документ показывает порядок их подключения, а не планы будущей разработки.

## 1. Автономное ядро

Папка **core** работает без сервера и установки программ. Прогресс сохраняется в браузере этого компьютера.

Проверка: открыть **core/index.html** или **start-core.bat** и пройти одну карточку.

## 2. Локальная полная версия

Папка **english_learning** содержит API, а папка **website** — сайт и админ-панель.

Локально используется SQLite. Windows-сценарии находятся в папке **scripts**.

Проверка: API health, обучение, словарь и **/admin.html** работают на локальном компьютере.

## 3. API и MySQL в Amvera

API разворачивается из собственной копии GitHub. MySQL создаётся отдельным проектом. Telegram-токен на этом этапе не нужен.

Подробности: [Amvera: API и MySQL](infoAmvara.md).

## 4. Сайт и админ-панель на REG.RU

Содержимое **website** публикуется на собственном домене. Сайт обращается к публичному HTTPS API, а API — к MySQL.

Админ-панель находится по адресу **/admin.html** и использует ADMIN_PASSWORD из Amvera.

Подробности: [REG.RU](reg-ru.md).

После этого этапа сайт является полностью рабочим и не зависит от Telegram.

## 5. Telegram-бот

Бот подключается последним к уже работающим API, MySQL и сайту. Сайт и бот используют общий Chat_ID и общий прогресс.

Подробности: [Telegram-бот](telegram-bot.md).

~~~text
Сайт REG.RU ──┐
              ├─ API Amvera ─ MySQL Amvera
Telegram ─────┘
~~~
