# Telegram-бот

Начинайте этот этап только после полной проверки сайта и админ-панели на REG.RU.

Telegram — дополнительный интерфейс к уже работающим API и MySQL. Если не выполнять этот этап, сайт продолжит работать самостоятельно.

## 1. Создайте бота

1. Откройте в Telegram официального бота **@BotFather**.
2. Выполните команду **/newbot**.
3. Укажите отображаемое имя, например **LearEnglish**.
4. Укажите свободный username, который заканчивается на **bot**.
5. Скопируйте выданный токен и сохраните его в закрытой заметке.
6. Не публикуйте токен в GitHub, config.js, сообщениях или скриншотах.

Username у каждого студента будет собственным. Не используйте пример **YOUR_BOT_USERNAME**.

## 2. Добавьте настройки в Amvera

Откройте приложение API и добавьте:

| Название | Тип | Значение |
|---|---|---|
| **TELEGRAM_BOT_TOKEN** | секрет | токен BotFather |
| **TELEGRAM_BOT_USERNAME** | обычная переменная | username без @ |
| **SITE_URL** | обычная переменная | https://ваш-домен |
| **API_URL** | обычная переменная | http://127.0.0.1:5000 |

API_URL остаётся локальным: бот и API запускаются внутри одного контейнера. Публичный адрес API для этой переменной не нужен.

Сохраните значения и перезапустите приложение.

## 3. Проверьте лог приложения

После запуска в логе должно появиться сообщение о запуске Telegram-интерфейса.

Если API работает, но бот не отвечает, проверьте:

- токен скопирован полностью;
- TELEGRAM_BOT_TOKEN создан как секрет запуска;
- TELEGRAM_BOT_USERNAME указан без @;
- приложение перезапущено после изменения переменных.

## 4. Проверьте бота отдельно

1. Откройте своего бота.
2. Нажмите **Start** или отправьте **/start**.
3. Откройте меню.
4. Запустите обучение.
5. Дайте один правильный и один неправильный ответ.
6. Откройте статистику.
7. Проверьте, что бот не показывает ошибки.

Неправильный ответ должен сохраняться в разделе сложных слов через API.

## 5. Добавьте ссылку на бота на сайт

В своей копии GitHub откройте **website/config.js**.

Укажите:

~~~javascript
window.ENGLISH_API_URL = 'https://ВАШ-API.amvera.io';
window.TELEGRAM_BOT_URL = 'https://t.me/ВАШ_USERNAME';
~~~

Не добавляйте @ после **t.me/** и не добавляйте токен.

Сохраните файл и повторно загрузите обновлённый **config.js** в корень сайта на REG.RU. Остальные файлы повторно загружать необязательно.

Обновите сайт сочетанием Ctrl+F5 или откройте приватное окно. В меню должна появиться кнопка Telegram.

## 6. Проверьте синхронизацию

1. Откройте сайт.
2. Запомните показанный Chat_ID.
3. Нажмите кнопку Telegram на сайте.
4. Нажмите Start в открывшемся боте.
5. Измените прогресс в боте.
6. Вернитесь на сайт через кнопку сайта в Telegram.
7. Убедитесь, что сайт показывает тот же прогресс.

## Частые ошибки

### Кнопка Telegram не появляется

Проверьте TELEGRAM_BOT_URL в загруженном на REG.RU **config.js**. Значение должно начинаться с **https://t.me/**.

Очистите кэш сочетанием Ctrl+F5.

### Бот запускается, но не открывает сайт

Проверьте SITE_URL в Amvera. Он должен содержать полный HTTPS-адрес сайта без лишнего пути.

### Бот показывает ошибку обращения к API

Проверьте, что API_URL равен:

~~~text
http://127.0.0.1:5000
~~~

Затем убедитесь, что **/api/health** публично возвращает status ok, и перезапустите приложение.

### Токен случайно попал в GitHub или скриншот

Немедленно отзовите токен через BotFather, создайте новый и замените TELEGRAM_BOT_TOKEN в Amvera. Простого удаления текста из GitHub недостаточно.
