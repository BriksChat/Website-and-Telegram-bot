# English Learning: API и Telegram-бот

Этот каталог содержит Flask REST API и шаблон Telegram-бота, которого студент создаст через BotFather.
Оба процесса разворачиваются в Amvera и работают с одной MySQL. Статический сайт
находится в `../website/` и может быть опубликован на выбранном студентом домене.

## Синхронизация

Опубликованный сайт отправляет HTTPS-запросы в развёрнутый API. Telegram-бот обращается к тому же
API. Общим идентификатором пользователя служит Telegram
`chat_id`; на сайте его можно установить кнопкой с карандашом рядом с Chat_ID.

## Запуск

Параметры MySQL, Telegram и CORS задаются переменными окружения. Полная инструкция
находится в `../docs/deployment.md`; зависимости перечислены в `requirements.txt`.
Не добавляйте токен бота или реквизиты MySQL в исходный код.
